# Raksha Bandhan Card ❤️

Static front-end website. No npm, backend, or database is required.

## GitHub structure

The repository ROOT must contain:

```text
index.html
assets/
  hero-brother-sister.png
  final-brother-sister.png
  memory-sample-1.png
  memory-sample-2.png
  memory-sample-3.png
```

Do NOT put `index.html` inside another nested folder.

## Vercel

Import the GitHub repository and deploy as a static site.

- Framework Preset: Other
- Build Command: leave empty
- Output Directory: `.`
- Install Command: leave empty

## Features

- Animated loading screen
- Hero brother/sister artwork
- Multi-page envelope letter
- No sound
- Rotating memory gallery
- Add/replace photos directly on the website
- Sister/brother names
- Custom message
- Save Changes
- Personalized share link
- WhatsApp sharing
- Mobile responsive

## Personalization

Choose images under **Customize Your Card**. Images are compressed in the browser and stored in the personalized URL fragment. There is no image upload server.

For reliable sharing, use a reasonable number of small photos. Very large photos can make the URL too long for browsers or messaging apps.
